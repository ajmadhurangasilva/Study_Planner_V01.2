# 📚 Study Planner V01.2

> **The next generation of Study Planner** — an enhanced version of **Study Planner V01.1**, designed to provide a smarter, more organized, and more productive learning experience for students.

---

## 🚀 Overview

Study Planner V01.2 is an upgraded version of the original Study Planner application with improved user experience, enhanced performance, and additional features to help students effectively manage their academic activities.

Whether you're preparing for exams, managing assignments, or organizing your weekly study schedule, Study Planner helps you stay focused and productive.

---

## ✨ Features

### 📅 Smart Study Planning
- Create personalized study plans
- Organize daily and weekly schedules
- Track completed study sessions

### 📚 Subject Management
- Add and manage subjects
- Categorize learning materials
- View subject-specific tasks

### ✅ Task Management
- Create study tasks
- Edit and delete tasks
- Mark tasks as completed
- Track pending activities

### 📊 Progress Tracking
- Monitor study progress
- View completed vs pending tasks
- Stay motivated with visual progress

### 🎨 Modern User Interface
- Responsive design
- Clean and intuitive layout
- User-friendly navigation
- Mobile-friendly experience

## ⚙️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/ajmadhurangasilva/Study_Palnner_V01.2.git
```

Move into the project directory

```bash
cd Study_Palnner_V01.2
```

### Install Frontend

```bash
cd client
npm install
npm start
```

### Install Backend

```bash
cd server
npm install
npm run dev
```
